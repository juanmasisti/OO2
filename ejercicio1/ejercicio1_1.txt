Bad smell:
Uncommunicative Name (y Comments): Los nombres de los métodos y sus parámetros no revelan su intención ni su propósito de negocio. Como consecuencia directa de esto, aparece el mal olor "Comments", ya que el programador original tuvo que escribir comentarios como "desodorante" para explicar lo que el código no puede explicar por sí mismo. 

Refactoring a aplicar: Rename Method (Renombrar Método) para las funciones, y Rename Variable/Parameter para los argumentos opacos.

public double limiteDeCredito() { ... }

protected double montoCobradoEntre(LocalDate fechaInicio, LocalDate fechaFin) { ... }
